# DayFold

Fold one day into a souvenir ticket. A mood, one line, a place, and a time stay on the device.

Package: `com.DayFoldMNG.DayFold`

Remote config: [N308.json](https://api2.blwsmartware.net/N308.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product ID | Type |
| --- | --- |
| `df_pack_1` … `df_pack_10` | Consumable coins |
| `df_remove_ads` | Non-consumable |
| `df_pro` | Non-consumable, more than 8 tickets |

No account. Share a ticket as an image.
